# Botania Revived

Наша доработанная сборка Botania Revived для Minecraft 1.21.1 / NeoForge. Текущая версия — **1.0.2-bbtt.4**.

Основа — [Botania Revived автора VelronDevs](https://www.curseforge.com/minecraft/mc-mods/botania-revived), [GitHub](https://github.com/Velron-Devs/Botania-Revived), исходная версия 1.0.2, коммит 06fe34c. Оригинальная Botania создана Vazkii и командой.

Ниже перечислены изменения относительно исходной Botania для 1.7.10 и конкретные наши исправления современной базы. Цветы, бассейны маны, линзы и остальные исходные возможности не считаются новыми добавлениями. Модернизация движка выполнена авторами Botania Revived; наши изменения касаются размещения структур и сохранённых шаблонов.

## Для запуска

Minecraft 1.21.1, Java 21, NeoForge 21.1.240+ и Patchouli 1.21.1-93-NEOFORGE или новее. В нашей сборке использовался NeoForge 21.1.264. Curios нужен для соответствующей бижутерии; остальные интеграции необязательны.

Скачайте [релиз 1.0.2-bbtt.4](https://github.com/yzs57phbts-web/botania-revived/releases/tag/1.21.1-v1.0.2-bbtt.4) и положите JAR в `mods`. Используйте одну версию Botania.

## Пофиксили

- В нашей доработке наземные декоративные структуры проверяют сухую опору, допустимые перепады поверхности и пересечения с зарегистрированными структурами.
- Сохранены исправленные шаблоны двух парящих островов; при переносе структур их NBT и водопады не переписывались.
- Чтение ранее сохранённых частей структур поддерживает старые идентификаторы, чтобы переход на нативные структуры Botania не ломал их загрузку.

## Адаптировали

- Авторы Botania Revived перенесли реестры, предметы, рецепты, сеть и отрисовку на NeoForge 1.21.1; книга использует Patchouli, бижутерия — Curios.
- Наши проверки размещения и миграция сохранённых структур используют современные StructureType/PieceType вместо внешнего обработчика bbtt-fixes.

## Добавили

- Нативный тип `botania:supported_template` для пяти групп декоративных структур и обработчик их сохранённых частей.
- Декодеры старых `bbtt_fixes:supported_template` с последующей записью в пространстве имён Botania.

## Изменили

- Пять JSON структур используют собственный тип Botania; их templateID, имена structure sets и остальные настройки сохранены.
- Исправления структуры находятся в самой Botania; обязательная зависимость от bbtt-fixes удалена.
- Поведение остальных систем и конфиги установленной сборки этой доработкой не менялись.

## Сборка и проверки

Исходники включают полную базу VelronDevs и наши изменения. Нужен Java 21; обычная команда сборки — `./gradlew build`.
Исходный автоматический workflow автора сохранён в `docs/upstream-workflows/` как справочный материал и не запускает публикации в нашем репозитории.

Опубликован точный установленный JAR. Для нативных структур ранее прошли 7 целевых серверных GameTest: опора, размещение, миграция старых ID, вращения, пересечения и сохранность островов. Это не проверка всех механик Botania; заново полный набор при публикации не запускался.
